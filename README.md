# Eman Arafa — Portfolio

Professional portfolio for Eman Arafa, a mechatronics technologist in Egypt. The page presents her vehicle and railway maintenance training, education, technical courses, and graduation project for recovering energy from railway cars.

The site is built with static HTML, CSS and JavaScript. Profile and training photographs and the railway background are stored in `assets/`; the graduation project image is stored in `assets/projects/`.

## Deploy to Vercel

Import the repository into Vercel using the **Other** framework preset. Leave the build command empty and set the output directory to `.`. The included `vercel.json` contains these settings; no build step or dependencies are required.
